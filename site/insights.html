What Uganda's tech companies build with

Languages, website platforms, hosting, email and hiring, measured from open data across the directory.

    How it's measured 5

    Each chart covers only the companies in the confident list where that signal could be found, and says how many that is. Nothing here comes from a survey.

    Languages

    The main language of public GitHub repositories pushed in the last two years, by Uganda-based developers who name the company on their profile and by the company's own GitHub organisation.

    Websites

    Platforms, frameworks, servers and analytics are detected from each homepage's HTML and response headers. They describe the public website, not necessarily the company's products.

    Hosting and email

    Hosting is the network that announces the website's IP address. "Behind Cloudflare" means the real host is hidden. Email comes from the domain's MX records.

    Hiring

    Technologies named on the company's own careers page. Few companies publish one, so treat these numbers as indicative.
