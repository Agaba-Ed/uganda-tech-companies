What Uganda's tech companies build with

Languages, website platforms, hosting, email and hiring, measured across the directory.

How these are measured

Every chart covers only the companies in the confident list for which that signal could be found, and says how many that is.

  • Languages: main languages of public GitHub repositories pushed in the last two years, by Uganda-based developers who name the company on their profile and by the company's own GitHub organisation. Counted once per company.
  • Website platform, frameworks, servers: detected from each company's homepage HTML and response headers. This describes the public website, not necessarily the company's products.
  • Hosting: the network that announces the website's IP address. "Behind Cloudflare" means the real host is hidden.
  • Email: from the domain's MX records.
  • Hiring: technologies named on the company's careers page.
